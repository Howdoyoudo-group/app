# Howdoyoudo

UK career exploration platform — helping people discover industries they love.

**Live site:** https://www.howdoyoudo.co.uk

## Stack
- React + Vite + TypeScript
- Supabase (database + edge functions)
- Vercel (hosting — auto-deploys from this repo)
- Google Gemini 2.5 Flash (AI)

## Getting started

```sh
git clone https://github.com/Howdoyoudo-group/app.git Howdoyoudo
cd Howdoyoudo
npm install
npm run dev
```

## Working on this project

Open the project in Claude Code — it reads `CLAUDE.md` automatically and has full context on the codebase, credentials, and what needs doing.

Always read `SESSION_LOG.md` before starting work to see what the other developer did last.

## Deployment

Vercel auto-deploys every push to `main`. Changes are live within ~1 minute of pushing.
